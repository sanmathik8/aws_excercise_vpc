# 10-Day AWS VPC Training Program

Welcome to the self-guided 10-day AWS VPC training program.

This program is structured into 5 hands-on, scenario-driven exercises covering 2 days per exercise:

- [Exercise 1 — Design a Highly Available VPC](EXERCISE_1_HIGHLY_AVAILABLE_VPC.md) (Days 1–2)
- [Exercise 2 — Public & Private Networking + NAT Gateway](EXERCISE_2_PUBLIC_PRIVATE_NAT.md) (Days 3–4)
- [Exercise 3 — Security & Network Troubleshooting](EXERCISE_3_SECURITY_NETWORK_TROUBLESHOOTING.md) (Days 5–6)
- [Exercise 4 — Private Connectivity: VPC Peering & VPC Endpoints](EXERCISE_4_VPC_PEERING_ENDPOINTS.md) (Days 7–8)
- [Exercise 5 — Master VPC Build & Troubleshooting](EXERCISE_5_MASTER_VPC_TROUBLESHOOTING.md) (Days 9–10)
